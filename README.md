# Student Report Card (OOP)

A simple Python OOP project that stores student records and subject marks, calculates the average, and checks pass or fail. A subject is failed if the marks are below 35.

## Features
- A `Student` class with roll number, name, and subject marks
- Add marks for any subject
- Calculate and print the average marks
- Check pass/fail and say which subject was failed

## How to run
You need Python 3. In a terminal:

```
python oop_challenge_program.py
```

## Sample output
```
Ajay's Avg is 32.5
Ajay failed in english
Result:  False

Ram's Avg is 91.0
Ram passed
Result:  True
```

## Concepts used
- Classes and objects
- Encapsulation: the marks are private (`__marks`)
- Dictionaries and basic result processing
